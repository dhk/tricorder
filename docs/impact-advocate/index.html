tricorder · impact-advocate

Make the case for your impact, from your own GitHub record

impact-advocate is an agent skill that mines your commits, pull requests and reviews over a window you choose, then writes a Markdown document that rates your work against your role and level. Every claim is linked or counted. Tricorder adds the evidence counts miss: ownership, expertise and the quality of your code review.

8 stepsPython 3.9+ · git · gh · Claude CodeNo API key requiredMarkdown version
Privacy-first: runs entirely inside your own Claude session, with your own access. No server, no telemetry, no extra AI provider. No API key is needed: GitHub access is a sign-in (gh auth login), and the two tricorder commands this guide uses (discover --history and analyze) call no AI provider. On an employer repo, check that your company's policy allows your Claude plan to read its code.
Self-directed only. The skill assesses the person running it, nobody else. Tricorder's constitution §6 rules out performance-review use with one narrow exception: you run it on yourself, you own the output, and no colleague is ranked.

02

Install tricorder

Clone the repository rather than installing from a package URL. The skill lives in the repository, not in the Python package.

git clone https://github.com/dhk/tricorder.git
cd tricorder
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -e .
tricorder --version

The virtual environment keeps tricorder out of your system Python. Run source .venv/bin/activate again in each new terminal. Avoid npm install dhk/tricorder unless you want npm to run pip install in whichever Python environment it finds.

03

Configure access

GitHub

The skill and tricorder both use the GitHub CLI:

gh auth login
gh auth status

Prefer a token? Create a fine-grained personal access token with read-only access to Contents, Pull requests, Issues and Metadata on the repositories you'll analyze. Tricorder checks GITHUB_TOKEN first, then gh auth token. Organizations with SSO need the token authorized for them.

export GITHUB_TOKEN=...            # never commit it

Keep artifacts out of git

Tricorder writes to .tricorder/ inside the repository you analyze, and those files can name colleagues. Exclude it locally:

echo ".tricorder/" >> .git/info/exclude
04

Install the skill

Claude Code

From the tricorder clone, copy the skill into your personal skills directory so it's available in every project:

mkdir -p ~/.claude/skills
cp -rf skills/impact-advocate ~/.claude/skills/

Claude Code picks up new skills without a restart. If ~/.claude/skills didn't exist when your session started, run /reload-skills. To scope the skill to one repository, copy it to that repository's .claude/skills/ instead. (Claude Code skills docs)

Claude.ai

Turn on code execution first: Settings → Capabilities on Free, Pro and Max; on Team and Enterprise an admin enables skills. Zip the folder so impact-advocate/ is the top level, then upload it under Customize → Skills → Upload a skill. (Using skills in Claude)

cd skills && zip -r ../impact-advocate.zip impact-advocate && cd ..

Claude.ai can't read your local clones, so you lose the git-history half of the evidence. Use Claude Code when you can.

Any other agent

Give it skills/impact-advocate/SKILL.md as instructions and the four files in references/ as context.

06

Run the skill

Start Claude Code in a working directory outside the repositories you're analyzing; the document is written there.

mkdir -p ~/impact && cd ~/impact
claude

Invoke the skill directly, or just ask:

/impact-advocate
Review season is coming up. Help me pull together my self-review from GitHub for the last six months.
  1. Interview. Three short rounds: scope and yardstick, what mattered, then context the repository can't show. Nothing runs until you say "go". To skip it, paste your answers from step 5 into the first message and say so; the skill lists every assumption at the top of the document.
  2. Harvest. It reads gh and local git history and logs the command behind every number.
  3. Rate. Each expectation gets Exceeds, Meets, or Not visible in GitHub. There's no "below": a repository shows that evidence exists far better than it shows that a behavior is missing.
  4. Write. You get impact-<login>-<start>-to-<end>.md: headline, scorecard, where you exceed, where you meet, goals, numbers, what isn't visible, next-level gap for promotion cases, tricorder suggestions, and a methodology appendix.
07

Add tricorder evidence

Counts flatten review work, which is often where senior impact lives. Two commands fill that gap. Run them from inside a repository you're analyzing, with the virtual environment active, and inspect .tricorder/ after each.

CommandAccessAdds to your case
tricorder discover --historyLocalContributors, hotspots and timeline: evidence for the areas you own
tricorder analyze OWNER/REPO --since 2026-04-01GitHub sign-inReview observations, an expertise map, and a local copy of every review and inline comment in the window

Set --since to the start of your window; analyze fetches PRs merged on or after it and excludes AI reviewers such as Copilot and CodeRabbit by default. Then let the skill do the reading. In the same Claude Code session, ask:

Read ~/src/REPO/.tricorder/OWNER__REPO/expertise-map.json and my reviews and inline comments
under ~/src/REPO/.tricorder/OWNER__REPO/.raw/reviews/ and .raw/comments/. Characterize how I
review: which areas, what I consistently push for, how often my approvals carry comments.
Cite PRs.

Use the real path to your clone; the session from step 6 runs in a different directory. Every point comes back traced to a PR you can link, and the data goes only to the Claude session you're already using. Tricorder's other commands are for team-level analysis, not a personal packet; see HOWTO.md if you want them.

Help

Troubleshooting

SymptomFix
tricorder: command not foundActivate the virtual environment in the tricorder clone.
Commit counts look lowThe clone is shallow or an email is missing. Run git fetch --unshallow and add every email from git log --format='%ae' | sort -u.
No review or PR timing dataThe skill had no GitHub access. Run gh auth login and ask it to re-harvest.
No GitHub token foundSet GITHUB_TOKEN or run gh auth login.
The skill can't find .tricorder/OWNER__REPO/Run tricorder analyze from inside that repository, and give the skill the full path.
The skill doesn't triggerInvoke it with /impact-advocate, or check that ~/.claude/skills/impact-advocate/SKILL.md exists.
Claude.ai rejects the uploadThe zip's top level must be the impact-advocate/ folder.
The skill won't assess a colleagueWorking as designed: it only builds your own packet.

Limits. GitHub isn't the whole job: incidents, design reviews and mentoring often leave little trace. Team comparisons need several contributors; in a solo repository the skill reports no baseline. The skill has been evaluated on two scenarios, both on a single-contributor repository using git only.
